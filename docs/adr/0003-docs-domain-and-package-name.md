# Docs at `docs.terza.dev`, package `terza-ui`

**Date:** 2026-10-30

The documentation site is served from `docs.terza.dev` on GitHub Pages. The npm package is the unscoped `terza-ui`, because the `terza` organisation on npm was already taken. The domain and the package name differ on purpose: the domain carries the brand and the package carries the product. Neither name should be "aligned" to match the other.
